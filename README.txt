# Blot

A little corner of your desktop for thoughts, reminders, and everything in between.

Blot is a lightweight Windows sticky notes app built with C# and WPF. Inspired by the classic Windows 7 Sticky Notes, it brings back the simplicity of having your notes right on your desktop.

## Features

- Create and manage multiple notes
- Drag, resize, and position notes freely
- Automatic saving and restoration
- Custom PNG note templates
- Five colour themes
- Rich text formatting
- Optional always-on-top mode
- System tray integration
- Launch on Windows startup
- Fully offline with local storage

## Built With

- C#
- WPF
- .NET 8

## Running Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Blot.git
```

Open the project in Visual Studio or VS Code and run:

```bash
dotnet restore
dotnet run
```

## Data Storage

Blot stores notes and settings locally on your computer.

```text
%AppData%\Blot
```

No accounts, cloud services, or internet connection required.
